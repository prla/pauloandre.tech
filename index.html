03 What I do

I focus on the system underneath the work.

  • Map decision-making — How priorities are actually being set.
  • Map flow — Where work slows down or gets stuck.
  • Make work visible — So reality, not opinion, drives decisions.
  • Identify the key constraint
  • Add simple feedback loops — So the system improves over time.
  • Define clear, actionable next moves

No frameworks. Just clarity.
